# Harmony-studio
This is my studio for harmony laboratory. It aims for personalized harmony dictionary building.
这是2026.11月初通过自己用ai作和声分析学习，然后尝试建立的一个网站。目前是v1.0版本，还没有配中文。自己尝试了拓宽范围，但效果不好。
例子选用的是金莎的《着迷》，有这首歌的和声分析。

想法是harmony_studio应该是类似一个和声实验室+和声字典的作用，希望起到如下作用：
1.随时查看，调用和声进行。
2.理解和声进行和其所对应的感受，建立理论/和声进行抽象符号与直观感受的桥梁，帮助人们更好地理解音乐，感受音乐，创造自己的音乐。
3.由于每个人的音乐品味，兴趣不同，每个人可以根据自己的品味和偏好建立属于自己的独一无二的音乐和声库。
