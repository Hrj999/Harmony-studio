      Add a song

      Start in 4/4; each bar has four beats. For an existing song, key and tempo keep its current chord map and recording alignment.

      Edit section

      Separate 4-beat bars with |. For durations use Fmaj7:2 C7:2; write rest for a full bar of silence. Editing a progression creates suggested voicings. A changed bar count recalculates later section times at the current tempo; check them against your recording.

      Hear this phrase in a whole-song variation

      This creates a separate song version with these bars replaced. The original song stays available. Compare it with the same melody and recording; a convincing chord on its own may behave differently in context.
