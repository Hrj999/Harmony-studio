HARMONY STUDIO

Double-click index.html. That single file contains the complete app.

Song Atlas and Phrase Lab now share one collection and one backup button.
Choose Back up everything to move the collection between browsers or computers.
Import backup accepts the combined backup or either of your earlier app backups.

TO UPLOAD TO YOUR GITHUB REPOSITORY
1. Extract the ZIP.
2. On GitHub choose Add file > Upload files.
3. Upload the CONTENTS of this folder, with index.html at the repository root.
4. Commit the upload. There is no installation or build step for you to run.

To make it a website, choose Settings > Pages > Deploy from a branch, then your
branch and / (root). See README.md for the optional source-build workflow.

Your personal browser collection is not in this ZIP. Keep your JSON backup.
The full song recording is not bundled; choose local audio in Song Atlas.
